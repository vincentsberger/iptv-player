# iOS Etappe 2 (Login + Live TV) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die iPhone-App wird benutzbar: anmelden (Xtream/M3U), Laden mit Übersicht, Startseite, Live TV mit Kategorien/Flaggen/Jetzt-Danach, Player mit Gesten, Senderliste und Zap-Karte – anstelle des Wiedergabe-Testbildschirms aus Etappe 1.

**Architecture:** `iosApp` bekommt eine Touch-Oberfläche in Compose Multiplatform, gesteuert von `AppState` aus `shared` (wie `desktopApp/Main.kt`). Logik, die bisher doppelt in `desktopApp` und `androidApp` steckt und jetzt ein dritter Abnehmer braucht (EPG-Fortschritt, Flaggen, Zeitformat), wandert vorher nach `shared`; die Gesten-Auswertung ist eine reine Funktion in `shared` und damit unter Linux testbar. Der Player ist ein `VlcController` (Zustandsobjekt um `VLCMediaPlayer`), dessen `UIView` beim Drehen erhalten bleibt.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform 1.9.3 (iOS), MobileVLCKit 3 (cinterop, vorhanden), Coil 3 + Ktor-Darwin (Bilder), UIKit/Foundation per Kotlin/Native.

**Spec:** `docs/superpowers/specs/2026-11-23-ios-app-design.md` (Abschnitte *Oberfläche*, *Player*, *Etappen → 2*)

## Review Focus

- **Drehen während der Wiedergabe:** Der Stream darf beim Wechsel Hochformat ↔ Querformat nicht neu starten (kein schwarzes Bild, kein erneutes Puffern) → `VlcController` lebt über dem Layout-Wechsel; Prüfpunkt im Gerätetest (Task 6).
- **App in den Hintergrund (Home-Taste, Anruf) und zurück:** Live startet den Sender neu, Film/Folge steht pausiert an derselben Stelle; Fortschritt ist gespeichert → `playbackOnBackground`/`playbackOnForeground`-Tests in Task 2.
- **Versehentlicher Senderwechsel:** kurze, schräge oder langsame Wischer (Daumen beim Halten) schalten nicht um; Wischen vom linken Rand öffnet die Senderliste statt umzuschalten → Schwellwert-Tests in Task 2.
- **Sehr große Senderlisten (≥ 10 000 Sender, „Alle Sender“):** Liste scrollt flüssig, EPG wird nur für sichtbare Zeilen angefragt → `LazyColumn` mit `key = url`, `requestEpg` nur in sichtbaren Zeilen; Prüfpunkt im Gerätetest mit Vincents Anbieter.
- **Notch/Dynamic Island und Home-Indikator im Querformat:** Bedienelemente und Senderliste liegen nie darunter → `WindowInsets.safeDrawing` auf allen Overlays; Prüfpunkt im Gerätetest.

### Task 2: Gesten und Hintergrund-Verhalten als reine Logik in `shared`

**Files:**
- Create: `shared/src/commonMain/kotlin/de/vincentsberger/iptvplayer/shared/touch/PlayerGestures.kt`
- Create: `shared/src/commonTest/kotlin/de/vincentsberger/iptvplayer/shared/touch/PlayerGesturesTest.kt`

**Interfaces:**
- Produces:
  ```kotlin
  enum class TouchAction { NONE, TOGGLE_CONTROLS, NEXT_CHANNEL, PREVIOUS_CHANNEL, OPEN_CHANNEL_LIST, SEEK_BACK, SEEK_FORWARD }
  /** Koordinaten in Pixeln; [density] = px je dp. */
  fun tapAction(x: Float, width: Float, doubleTap: Boolean, isLive: Boolean): TouchAction
  fun swipeAction(startX: Float, dx: Float, dy: Float, durationMs: Long, density: Float, isLive: Boolean): TouchAction
  enum class BackgroundAction { STOP, PAUSE }
  enum class ForegroundAction { RESTART, STAY_PAUSED }
  fun playbackOnBackground(isLive: Boolean): BackgroundAction   // Live → STOP, sonst PAUSE
  fun playbackOnForeground(isLive: Boolean): ForegroundAction   // Live → RESTART, sonst STAY_PAUSED
  ```
- Regeln: Einfachtipp → `TOGGLE_CONTROLS`. Doppeltipp bei Film/Folge im linken Drittel → `SEEK_BACK` (−10 s), rechten Drittel → `SEEK_FORWARD` (+30 s), Mitte → `TOGGLE_CONTROLS`; bei Live immer `TOGGLE_CONTROLS`. Wischen (nur Live): Start ≤ 24 dp vom linken Rand und `dx` ≥ 60 dp → `OPEN_CHANNEL_LIST`; sonst senkrecht, wenn `|dy|` ≥ 60 dp, `|dy|` ≥ 2·`|dx|` und Dauer ≤ 600 ms: nach oben (`dy < 0`) → `NEXT_CHANNEL`, nach unten → `PREVIOUS_CHANNEL`; alles andere → `NONE`.

  @Test fun swipeUpIsNextChannel() = assertEquals(NEXT_CHANNEL, swipeAction(600f, 0f, -200f, 200, 3f, true))

  @Test fun backgroundAndForeground() { assertEquals(STOP, playbackOnBackground(true)); assertEquals(PAUSE, playbackOnBackground(false)); assertEquals(RESTART, playbackOnForeground(true)); assertEquals(STAY_PAUSED, playbackOnForeground(false)) }
