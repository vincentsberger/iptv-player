## Review Focus
- **Kontextmenü auf einem Sender:** keine „Details“/„Herunterladen“-Einträge, nur Favorit und Kategorie ausblenden.
- **Kontextmenü bei Titel ohne Anbieter-Kategorie (Genre-Raster, Suche):** „ausblenden“ nennt die echte Kategorie des Titels.
- **Downloads leer / nur Fehler:** Gruppen ohne Einträge erscheinen nicht; Speicherbalken stimmt bei 0 Bytes.
- **Suche: Begriff mit einem Buchstaben:** keine Treffer-Ansicht, Zuletzt-gesucht bleibt sichtbar.
- **Einstellungen: alle bisherigen Optionen bleiben erreichbar** (Querformat, neueste zuerst, Reihen, Neu-Kategorien, Länder, Lizenzen, Abmelden).

### Task 1: Kontextmenü (P13)
`design/ContextMenu.kt` (neu), `IosApp.kt`, Aufrufer von `onLongClick` (`PosterCard`, `LandscapeCard`, `ChannelRow`), Detailseiten-„Mehr“.
- `object ContextMenu { fun show(item: Item) }` + `ContextMenuHost(app)`: Hintergrund unscharf (`Modifier.blur(16.dp)` auf dem Inhalt) und abgedunkelt (bg @60 %), angehobenes Poster 168×250 (Sender: Logo-Kachel 96), darunter Menü (surface1, Rand line, Zeilen 48 dp: Text links, Symbol rechts): „Zu Favoriten“/„Aus Favoriten“, „Herunterladen“ (nur ladbare Titel), „Details“ (Filme/Serien), abgesetzt (6-dp-Fuge) „„<Kategorie>“ ausblenden“. Tippen außerhalb schließt; jede Aktion mit Rückmeldung.
- Langes Drücken auf Postern, Querkarten und Senderzeilen öffnet das Menü statt sofort umzuschalten.

### Task 2: Suche
`SearchTab.kt`: `TitleBar("Suche")`, `SearchField` + „Abbrechen“ (bei Begriff); leer: „Zuletzt gesucht“ (`SectionHeader` mit „Löschen“, Chips mit Verlaufs-Symbol), „Kategorien entdecken“ (`ListGroup`: zuletzt gewählte Live-Kategorie, Filme · Neu (7 Tage) falls vorhanden, Serien · häufigstes Genre), Fußnote. Treffer: Filter-Chips „Alle n / Live TV n / Filme n / Serien n“, Abschnitte mit `SectionHeader` (Anzahl rechts), Sender als `ChannelRow`, Filme als `PosterCard`-Reihe, Serien als Zeilen (Bild 64×40, Name mit markiertem Suchbegriff, Kennzeile, Pfeil).

### Task 3: Favoriten und Downloads
`FavoritesScreen.kt`: `BackBar("Start")`, `H1`, Filter-Chips mit Anzahl, Abschnitte (Sender-Zeilen, Poster-Reihen). „Bearbeiten“ entfällt – entfernen über Stern/Kontextmenü.
`DownloadsScreen.kt`: `BackBar("Start")`, `H1`, Speicherbalken 6 dp (belegt text, ladend signal, frei surface2) + Zeile „6 Titel · 12,4 GB belegt / noch 38,1 GB frei“; Gruppen in der Reihenfolge Läuft, Fehler, Wartet, Fertig (`GroupLabel`), Zeilen: Poster 44×64 (Film) bzw. Bild 78×44 (Folge), Titel, Statuszeile, Fortschritt; rechts × (läuft), „Erneut“ (Fehler), Uhr (wartet), Haken (fertig). Wischen zum Löschen bleibt.

### Task 4: Einstellungen
`SettingsScreen.kt`: `BackBar("Start")` + `H1`; Gruppen über `GroupLabel` + gerahmte surface1-Fläche; Schalter = `design.Toggle`; Länder/Neu-Kategorien als `Chip(small)` mit Flagge; Löschen/Abmelden in danger; Version Mono. Alle bisherigen Einträge bleiben.
