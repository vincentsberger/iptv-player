# Programmführer-Raster (TV) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Senderliste im TV-Player (`ChannelGuide`) wird zum EPG-Raster: Sender untereinander, Sendungen auf einer gemeinsamen Zeitleiste, Start bei „jetzt“.

**Architecture:** Reine Raster-Logik (Zellen, Grenzen, Navigation, Fenster) als Funktionen in `shared` (`EpgGrid.kt`), damit PC/iPhone sie später nutzen. `EpgStore` lädt das Programm je sichtbarem Sender über eine Warteschlange (max. 4 parallel, neueste zuerst, wartende verwerfbar). Die TV-UI rendert das Raster als **ein** fokussierbares Element mit eigener Tastenbehandlung (Fokus-Zustand = Zeile + Zelle), nicht über Compose-Fokus zwischen Zellen.

**Tech Stack:** Kotlin Multiplatform, Compose (androidx + tv-material), kotlinx.coroutines, Python-Demo-Server.

**Spec:** `docs/superpowers/specs/2026-11-28-epg-grid-design.md`

## Global Constraints

- Branch `feat/epg-grid-design` (enthält Spec + Roadmap-Commit). Commits englisch, **ohne Co-Authored-By**; KDoc/Kommentare deutsch; Zeilen bis 160.
- Zeiten nur im Maßstab `startAt`/`endAt`/`localNow()` („yyyy-MM-dd HH:mm:ss“) über `epgSeconds` – nie Timestamps. Programme gehen durch `cleaned()`.
- Höchstens **4 gleichzeitige** Programm-Abrufe; `programmeFetchedAt` erst nach **erfolgreichem** Laden setzen; Anbieterwechsel-Schutz `session.repo === r` bleibt.
- Sichtbares Fenster **2 Stunden**, Kopfzeile halbstündlich, Fensterbeginn beim Öffnen = letzte volle/halbe Stunde vor „jetzt“.
- Eine Zeitachse fürs ganze Raster: linke Grenze `jetzt − max(archiveDays)·86400` der Kategorie, ohne Archiv = Fensterbeginn beim Öffnen; rechte Grenze = spätestes Datenende, mindestens Fensterende.
- Farben nur aus `Palette.kt`/Tokens der TV-App, Bernstein nur für Auswahl/„Live“/Fortschritt (`.tastemaker/style-lock.md`).
- AppState bleibt Fassade: neue Funktionen ins Interface `Epg`, AppState delegiert schon (`Epg by epg`).
- Keine Änderung an PC/iPhone-UI; beide müssen weiter kompilieren.

## Review Focus

- Anbieter liefert Sendungen ohne lesbare `startAt`/`endAt` (nur Uhrzeit-Texte) → solche Einträge fallen aus dem Raster, die Zeile zeigt „Keine Programmdaten“ statt abzustürzen (Test in Task 1).
- Sendung länger als das Fenster (z. B. 6 h Sport) → eine Zelle, an beiden Seiten abgeschnitten; ▶ springt darüber hinaus und das Fenster folgt (Test in Task 1).
- Kopfzeile über Mitternacht → Uhrzeiten laufen weiter, beim Tageswechsel steht der Tag dabei (Task 4, von Hand).
- Anbieterwechsel bei offenem Raster → Zeilen zeigen wieder „wird geladen“, keine Daten des alten Anbieters (bestehender Test + Test in Task 2).
- Kategorie, deren Sender alle `hasEpg = false` haben → keine Abrufe, Zeilen „Keine Programmdaten“, OK schaltet um (Test in Task 2).

### Task 1: Raster-Logik in `shared`

**Files:**
- Create: `shared/src/commonMain/kotlin/de/vincentsberger/iptvplayer/shared/EpgGrid.kt`
- Test: `shared/src/commonTest/kotlin/de/vincentsberger/iptvplayer/shared/EpgGridTest.kt`

**Interfaces:**
- Consumes: `EpgEntry`, `epgSeconds(text): Long?` (internal, `data/Models.kt:139`).
- Produces (package `de.vincentsberger.iptvplayer.shared`):
  - `enum class Airing { PAST, NOW, FUTURE }`
  - `data class GridCell(val entry: EpgEntry?, val start: Long, val end: Long)` – Sekunden im `epgSeconds`-Maßstab; `entry == null` = Lücke/keine Daten.
  - `object EpgGrid` mit `const val SLOT_S = 1800L`, `const val VISIBLE_S = 7200L` und:
    - `fun openingStart(now: Long): Long` – abgerundet auf `SLOT_S`.
    - `fun leftLimit(now: Long, openingStart: Long, maxArchiveDays: Int): Long`
    - `fun rightLimit(rows: List<List<EpgEntry>>, openingStart: Long): Long` – max. Ende, mindestens `openingStart + VISIBLE_S`.
    - `fun cells(entries: List<EpgEntry>, from: Long, to: Long): List<GridCell>` – lückenlos von `from` bis `to`, zugeschnitten; unlesbare Zeiten ignoriert; ohne Daten genau eine Zelle `entry = null`.
    - `fun cellAt(cells: List<GridCell>, time: Long): Int` – Index der Zelle, die `time` überdeckt; außerhalb geklemmt auf erste/letzte.
    - `fun anchorOf(cell: GridCell, windowStart: Long): Long` = `max(cell.start, windowStart)`.
    - `fun scrollTo(windowStart: Long, cell: GridCell, left: Long, right: Long): Long` – neuer Fensterbeginn, damit `cell` sichtbar ist; Ergebnis auf `SLOT_S` gerastert, geklemmt auf `[left, right − VISIBLE_S]`. Regel: `cell.start < windowStart` → `floorSlot(cell.start)`; `cell.end > windowStart + VISIBLE_S` → `min(ceilSlot(cell.end − VISIBLE_S), floorSlot(cell.start))`; sonst unverändert. Zusätzlicher Test `scrollToLongShowShowsItsStart`: Fenster 20:00, Zelle 18:00–23:59, left 17:00 → 18:00.
    - `fun airing(entry: EpgEntry, now: Long): Airing` – über `epgSeconds(startAt/endAt)`; unlesbar → `FUTURE`.
