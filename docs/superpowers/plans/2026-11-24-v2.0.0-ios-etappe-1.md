# v2.0.0 iPhone, Etappe 1 – Fundament, Einstieg Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das iPhone bekommt die Grundbausteine des freigegebenen Entwurfs (Farben, Schrift, Bausteine, Tab-Leiste,
Rückmeldung, Lade-Platzhalter, Logo-Kacheln) und die drei Einstiegs-Bildschirme Login, Laden und Übersicht.

**Architecture:** Logik und Texte, die alle Apps teilen könnten, kommen nach `shared` (mit Tests in `commonTest`),
die Oberfläche bleibt in `iosUi` (Compose Multiplatform). Neue Bausteine landen in eigenen Dateien unter
`iosUi/.../ui/design/`, damit Etappe 2–5 sie nur noch einsetzen.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform (Material3 als Unterbau, eigenes Aussehen), kotlin.test.

**Spec:** Entwurf https://claude.ai/artifact/KcaZEdqsG9xusKnF6v3d9n (Artboards „Einleitung und Style-Lock“,
„Bausteine“, „21 Tab-Leiste“, „20 Lade-Platzhalter“, „19 Rückmeldung“, „1 Login“, „2a Playlist wird geladen“,
„2b Übersicht nach dem Laden“, Werte aus `project/phone.css`), `docs/superpowers/plans/2026-11-24-v2.0.0.md`,
`.tastemaker/style-lock.md`.

## Global Constraints

- Farben exakt aus dem Style-Lock: bg `#16181B`, surface1 `#202327`, surface2 `#2B2F34`, line `#34383E`,
  text `#E6E8EB`, muted `#9BA1A8`, signal `#FF453A`, on-signal `#16181B`, danger `#FF8A65`.
- Signal nie als Textfarbe auf surface2; Auswahl immer mit Signal-Strich (2 dp unten), nie nur über die Fläche.
- Ecken 4 dp, klein 2 dp; keine Kapseln, keine Schatten, Haarlinien in `line`.
- Schrift Archivo (Titel SemiBold, Laufweite −2 %), IBM Plex Mono für Zahlen/Uhrzeiten, `tnum` überall.
- Code-Bezeichner englisch, Texte in der App deutsch.
- Entschieden 24.11.2026: Login bekommt „Name in der App“, **kein** EPG-Feld für M3U (eigener Punkt nach v2.0.0).
  Ladebildschirm bekommt „Abbrechen“ und „Live TV“; Teilfortschritt innerhalb eines Bereichs gibt es nicht,
  der Gesamtbalken zählt fertige Bereiche.
- Bauen/Prüfen unter Linux: `./gradlew :shared:desktopTest :iosUi:compileKotlinIosSimulatorArm64`;
  die `.ipa` baut die CI (Workflow `iOS`), installiert und geprüft wird auf dem iPhone.

## Review Focus

- **Abbrechen, während ein Bereich aus dem Zwischenspeicher schon da ist:** Abbrechen darf keine schon geladenen
  Bereiche verwerfen – nur die noch ladenden gelten als abgebrochen. Test in Task 2.
- **„Live TV“ früh öffnen, danach lädt ein anderer Bereich fertig:** Es darf keine Übersicht mehr aufspringen.
  Test in Task 2.
- **Name je Anbieter beim erneuten Anmelden ohne Namen:** Der gespeicherte Name bleibt erhalten. Test in Task 1.
- **Leerer/nur aus Leerzeichen bestehender Name:** zählt als kein Name, es erscheint `labelOf(account)`. Test in Task 1.
- **Logo-URL lädt nicht / Name ohne Buchstaben:** Kachel zeigt Initialen bzw. „TV“, nie eine leere helle Fläche.
  Test für `initialsOf` in Task 3.
