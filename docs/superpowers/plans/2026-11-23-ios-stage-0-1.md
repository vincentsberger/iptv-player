# iOS Etappe 0 + 1 (Versions-Update, Gerüst) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alle Apps auf aktuelle Kotlin/Compose-Versionen heben, dann `shared` für iOS bauen und eine unsignierte iPhone-App aus der CI erzeugen, die startet und einen Test-Stream über MobileVLCKit abspielt.

**Architecture:** `shared` und `testing` bekommen die Targets `iosArm64` + `iosSimulatorArm64` mit `iosMain`-Actuals (NSURLSession, Dateien, Keychain). Neues Gradle-Modul `iosApp` (Kotlin Multiplatform + Compose) liefert ein statisches Framework `IptvApp`; ein per XcodeGen erzeugtes Xcode-Projekt bettet es zusammen mit `MobileVLCKit.framework` in die App. Alles iOS-Spezifische baut und testet ausschließlich GitHub Actions (`macos-latest`).

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform (iOS), kotlinx-io, Foundation/Security per Kotlin/Native-Plattformbibliotheken, MobileVLCKit 3 (cinterop), XcodeGen, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-23-ios-app-design.md`

## Global Constraints

- Entwicklung unter Linux: Jeder Schritt, der iOS kompiliert oder testet, wird **per Push auf den Branch `ios-scaffold` und `gh run watch`** verifiziert, nie lokal. Lokal laufen nur JVM/Android-Tests.
- Bestehende Apps dürfen nicht instabiler werden: Nach jedem Task bleiben `./gradlew :shared:desktopTest :desktopApp:test :androidApp:testDebugUnitTest :androidApp:assembleDebug` grün.
- Kein zweiter Logik-Stand: Was in `shared` steht, wird in `iosApp` nicht nachgebaut.
- Fehlermeldungen dürfen nie die URL enthalten (Benutzername/Passwort stecken darin).
- Bundle-ID `de.vincentsberger.iptvplayer`, Anzeigename „IPTV Player“, Mindest-iOS 16.0, nur iPhone (`TARGETED_DEVICE_FAMILY = 1`).
- Zielgerät zum manuellen Test: iPhone 11, iOS 27.
- Die `.ipa` ist **unsigniert** (`CODE_SIGNING_ALLOWED=NO`); signiert wird beim Sideloading.
- Ein fehlschlagender iOS-Build blockiert kein Release.
- VLCKit muss **dynamisch** eingebettet sein (LGPL); ist das gelieferte Framework statisch → anhalten und Vincent fragen.
- Code-Bezeichner englisch, Kommentare/Doku/UI-Texte deutsch (wie im Bestand).
- Commits ohne `Co-Authored-By`-Trailer.

## Review Focus

- **M3U mit `\r\n`-Zeilenenden und ohne abschließenden Zeilenumbruch:** Zeilen kommen ohne `\r` an, letzte Zeile geht nicht verloren → Test in Task 2.
- **Riesige M3U-Listen (≥ 100 MB):** `httpReadLines` darf die Antwort nie komplett im Speicher halten → Download in Datei, zeilenweise lesen; Test `tempFileIsDeletedAfterReading` in Task 2.
- **Absturz/Abbruch beim Speichern:** Eine halb geschriebene Datei darf vorhandene Daten nicht zerstören (temporäre Datei + Umbenennen) → Test in Task 3.
- **Stream aus dem Heimnetz (Demo-Server, `http://192.168.x.y:8099`):** braucht ATS-Ausnahme und Local-Network-Freigabe, sonst stilles Scheitern → Info.plist in Task 4, manueller Test in Task 5.
- **`http://`-Server mit Port > 65535 oder Leerzeichen in der Adresse:** verständliche Meldung ohne Zugangsdaten statt Absturz → Test in Task 2.
